# Grille du rapport de Max (essai)

- Le rapport est un seul fichier `report.md` dans `/mnt/session/outputs/`, en français, avec les quatre parties « Constat », « Cause probable », « Gravité » et « Action proposée », dans cet ordre.
- Le constat est chiffré et daté : il cite l'instant fourni par l'outil et reprend les valeurs des règles actives ou des compteurs, sans en arrondir ni en changer aucune.
- La cause probable s'appuie uniquement sur les pistes fournies pour les règles actives ; si aucune règle n'est active, elle dit que rien d'anormal n'est constaté, sans chercher de cause.
- La gravité reprend le niveau le plus haut parmi les règles actives (info, important, critique), ou dit « aucune » quand aucune règle n'est active.
- L'action proposée est une action concrète pour Justin, tirée des pistes, sans prétendre qu'elle a déjà été faite ; « aucune action » quand rien n'est actif.
- Rien n'est inventé : aucun chiffre, aucune règle, aucun nom d'entreprise, de client ou de personne qui ne figure pas dans les faits de l'outil ; ce qui manque est écrit « non disponible ».
