Commence par **PROMPT-CLAUDE-CODE.md** (à coller dans Claude Code), puis **THEME-GLOBAL.md**.

```
THEME-GLOBAL.md          communs : mode, verre, typo, rayons, onglets, statuts, plateformes
PROMPT-CLAUDE-CODE.md    prompt prêt à coller
support.js               runtime des maquettes (à laisser à côté des sources/*.dc.html)
assets/                  logos TEAM OP · OP GESTION · OP MESSAGES
site/        THEME-SITE.md · sources/ · builds/
opgestion/   THEME-OPGESTION.md · README-ECRANS.md · VERSIONS.md · sources/ · builds/
opmessages/  THEME-OPMESSAGES.md · sources/ · builds/
tour/        THEME-TOUR.md · sources/ (PC + téléphones) · builds/
```

Chaque `builds/*.html` s'ouvre directement dans un navigateur : sélecteur de plateforme / d'écran en haut, jour et nuit visibles.
